# om-xample (redirect)

This repository exists only to redirect the old GitHub Pages address to the new one.

- Old address: `https://toddwmac.github.io/om-xample/` (this repo's Pages site)
- New address: **https://toddwmac.github.io/om-hub/**

`index.html` does a zero-second `<meta http-equiv="refresh">` redirect (plus a JS
fallback and a visible link) to the new site. GitHub Pages publishes this repo's
root, so visiting the old URL bounces visitors to OM Hub automatically.

The actual project now lives at [github.com/toddwmac/om-hub](https://github.com/toddwmac/om-hub).
